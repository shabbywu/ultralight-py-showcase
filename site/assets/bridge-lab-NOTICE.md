# Bridge Lab demo assets / 展示素材说明

Source: https://github.com/shabbywu/ultralight-py-showcase/tree/main/examples/bridge-lab

`bridge-lab-demo.webp`, `bridge-lab-poster.png`, and `bridge-lab.png` are recordings/captures of the actual Bridge Lab AppCore window using ultralight-py 0.5.0. The recording executes real editable Python/JavaScript examples, including 42 → 52, a live object proxy, and an asynchronous Promise. Frames are resized and compressed for the web; no outputs are composited or generated.
